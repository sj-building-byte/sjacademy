# Accuracy and fact-check rule

This rule applies to every piece of work that teaches, solves or states a fact: videos, reels, carousels, posts, PDFs and web pages. A wrong or confusing solution does more damage to SJ Academy than no post at all, so nothing is published until it passes every step below.

Set 17 October 2026. Read it together with `FACTS.md`, which covers claims about the academy.

## 1. Solve it twice
- Solve every question yourself before building anything, then solve it again a second way: a different method, a computed check (a short script), or substituting the answer back.
- Write the working and the answer in the project's `BRIEF.md`.
- If the two results disagree, stop and find out why before going on.

## 2. The question must be complete
- State every condition the answer depends on: regular, square, diameter, right angle, parallel, "not to scale", units.
- Define every letter on screen (for example, "n = number of sides").
- Ask yourself: could a student solve this from what is on screen and nothing else? If not, add what is missing.
- If another reading gives a different answer, reword the question until only one reading is possible.

## 3. The diagram must be honest
- Draw to the proportions given, or label it "not to scale".
- Every marking must match the text: right-angle marks, equal-side ticks, parallel arrows, labels on the right sides and angles.
- The diagram must not give the answer away before the reveal: no sides to count, no lengths a student can measure, no answer shown early.

## 4. Notation and wording
- Use the same units everywhere (diagram, steps, answer card, end card, caption).
- Use correct symbols: °, ², −, ×, ÷.
- Use the terms the CAIE syllabus uses.
- Each step follows from the one before it, with no jumps.

## 5. Tips, shortcuts and extra facts
- Every tip must be true in general, not only for this example.
- Name the condition it depends on, for example "Cyclic quadrilateral: opposite angles add to 180°", not "Cyclic quad: 180°".
- Cut any tip too short to be correct. Shorthand that a student could misread is a mistake.

## 6. Watch it as a student
Snapshot each of these frames and read it as a student seeing it for the first time:
- the question
- mid-countdown
- each reveal step
- the answer
- the tip
- the end card

For each frame, confirm three things:
- It makes sense on its own, with nothing undefined, missing or contradictory.
- The answer is not visible before the reveal.
- The text is readable and nothing overlaps.

## 7. Record it
Before moving a file to `✅ Finished/`, add an "Accuracy check" section to the project's `BRIEF.md`. It lists what was checked, the date and the result.

## 8. If a mistake gets through
- Fix it.
- Replace the file in `✅ Finished/`.
- Note the mistake and the fix in the project's `BRIEF.md`.
- If it was already posted, tell Sunyyan so the post can be corrected or taken down.
