# Brand: start here

The single source for how SJ Academy looks, sounds and moves. If any other folder has a style file that disagrees, this folder wins.

## Brand system v4.2 (12 October 2026)

Read the brand book first, then the playbook for the channel you are working in.

- `SJ-ACADEMY-BRAND-BOOK.md`: the core. The desk idea, the 7 locked assets (sonic logo pending), the proposed brand platform, expression levels (Calm, Clear, Loud), colour, type (Poppins and Caveat only), the five-line brief, open decisions and the 30-day rollout.
- `SJ-ACADEMY-WEB-PLAYBOOK.md`: the website design system (was the brand guidelines v3.2, now 3.3). Page families, components, tokens, accessibility, build rules.
- `SJ-ACADEMY-SOCIAL-ADS-PLAYBOOK.md`: posts, carousels, stories, static ads, thumbnails. Six formats (F1 to F6), the share test, monthly measurement.
- `SJ-ACADEMY-VIDEO-MOTION-PLAYBOOK.md`: every kind of video. Motion language (five desk moves, timing, easing), captions, shooting standards, recipes, video tokens.
- `SJ-ACADEMY-SOUND-PLAYBOOK.md`: sonic logo, desk sound kit, music, voice, mixing, licensing.
- `SJ-ACADEMY-PDF-PRINT-PLAYBOOK.md`: handouts, worksheets, lesson decks, posters, certificates.
- `sj-academy-brand-book.html`: the visual brand book. Audit, formats, live motion and sound demos. Open in a browser.
- `Sound/`: prototype sonic logo (full and short) and five desk sounds (WAV, with MP3 copies), and `licence-log.csv`. Cut prototypes are in `Sound/Archive/`.
- `Images/`: real photos used by the visual brand book.

## Other current files
- `sj-brand.css` and `sj-brand.min.css`: shared site stylesheet v3.1.1. The minified copy is what sits in WordPress > Appearance > Customize > Additional CSS, below the older custom CSS. When replacing it, select only from the `/*! sj-brand.css` line down.
- `sj-academy-brand-kit-v3.html`: every web element and component, live. Copy markup from here.
- `SJ-ACADEMY-LANDING-PAGE-COPY-GUIDELINES.md` (v1.2) and `sj-academy-landing-copy-guide.html`: copy for the homepage, level, subject and event pages.
- `SJ-ACADEMY-BLOG-VOICE-GUIDELINES.md` (v1.3) and `sj-academy-voice-tone-guide.html`: blog voice.
- `STYLE-GUIDE-DEEP-REVIEW.md`: open web review decisions, parked for later.
- `Logos/SVG/`: 13 clean logo SVGs. The Illustrator masters are in `Logos/`.
- `Templates/`: letterhead.

## Open decisions (brand book, section 12)
- What every piece says: the three pillars (Method, Teachers, Access).
- Brand promise or tagline (none set).
- The sonic logo (prototype; record properly once approved).
- Review wording: FACTS.md says "226+ five-star Google reviews"; v3 banned that wording.

## Rules
- Change the brand here only, then roll it out. Bump the version number in the file when you do.
- The core (brand book section 3) changes rarely. Formats, sounds and moves are added to the playbooks whenever they work.
- `Archive/` holds superseded guides (v1, v3.2, the old `sja_brand_style_guide.md`). Do not build from them.
