Brand system v4.2

Lock the assets. Free the ideas.

A few things never change, so people always know it's SJ Academy. Everything else is free to change, so nothing looks like the last post.

The five rules

  1. Lock the assets. Logo, yellow, highlighter, red pen, Poppins, the voice, real people.
  2. Start with the brief, never with the last file.
  3. Pick a level: Calm, Clear or Loud.
  4. One idea per frame. Two ideas, two frames.
  5. Only true things. Real facts, real people, real work.

Is it on brand?

  1. Does it carry the core: logo where needed, yellow, highlighter, Poppins?
  2. Is it true: real people, real work, facts from FACTS.md?
  3. Would a good teacher be happy to have made it? Funny is fine. Mean is not.

yes to all three? ship it.
