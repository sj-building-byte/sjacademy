# Voiceovers

Scripts and voice recordings for SJ Academy videos. Each video gets its own folder, holding:
- the script to read, for example `Gravity script.md`
- the recordings, saved straight into the same folder (any name, .m4a is fine)

Video projects copy the take they use into their own `assets/` folder, so nothing here gets moved or renamed.

## Recording on the Mac (QuickTime Player)
1. Open QuickTime Player, then choose File > New Audio Recording.
2. Click the small arrow next to the red button. Pick the microphone and set Quality to Maximum.
3. Stay silent for 2 seconds, then read the script.
4. Press Stop, then Cmd+S. Save into this video's folder.
